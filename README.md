## 🦋 About Meino3D

**Official Website (JP / EN):** https://xooox.ooo/

**Download:** [GitHub Releases](https://github.com/Meino3D/Meino3D/releases)

Meino3D is a free building and decoration mod for Minecraft, featuring original 3D blocks, furniture, plants, and decorative items.

Many of its blocks are designed to complement the aesthetic of Mizuno's resource pack.

Meino3D is an independent, personal project developed by a solo creator.

## 📦 Requirements

- Minecraft 26.3
- Fabric Loader 0.20.1
- Fabric API 0.167.0+26.3

**Recommended (Optional):**

- Mod Menu 21.0.1

Mod Menu allows you to enable or disable Meino3D's vanilla block replacements.

## 🎨 AI Usage & Development

ChatGPT is used for:

- Java programming and mod functionality
- JSON configuration files, including recipes and blockstates
- Website development (HTML, CSS, and JavaScript)
- Technical learning, troubleshooting, and code improvement
- Website proofreading and English translation

Generative AI is not used to create:

- Original illustrations and textures
- 3D block models and visual designs
- Visual designs for configuration screens

These original visual assets and designs are created by the creator.

For more information about AI usage, the creator's approach, and behind-the-scenes development, please visit the official website.
